2. Route the observed pressure to the catalogs in `references/`.
3. Judge with `references/judge-protocol.md`: evidence ladder, grounding taxonomy, the eight adversarial passes, and the Apply / Reject / Investigate rule.
4. Report findings only where you can name the failure and show the proof. Severity P0/P1/P2. An empty findings list is a legitimate result.

Use `--tribunal magi` only for high blast radius, irreversible, or security-sensitive work, and only when the human asks for it.
